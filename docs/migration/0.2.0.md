# Migrating to 0.2.0

Every component is closed: it takes typed props and no `className` or `style`. This page lists each 0.1.0 prop or class and its 0.2.0 replacement. The reasons are in `docs/adr/0001-own-shadcn-with-a-closed-api.md`.

## Everywhere

- Wrap the app in `<DesignSystemProvider linkComponent={RouterLink}>`. `ButtonLink`, `TextLink`, `DropdownMenuLinkItem`, `ItemLink`, `BreadcrumbLink`, pagination links, `NavigationMenuLink` and sidebar links render the product router link.
- Replace spacing and layout classes with `Stack`, `Inline`, `Columns` with `Column`, and `Spread`. Replace text classes with `Text` and `Heading`.
- A fixed width on a component becomes a sized container around it, plus `width="fill"` where the component has it.
- A look with no prop is a request to the design system. `Box` builds a product component that needs one, with tokens only.

| `buttonVariants(…)` on another element               | removed; use `ButtonLink` or a component                   |
