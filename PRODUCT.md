# Nanostack design system
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
React and TypeScript, based on shadcn/ui and Base UI, as requested. Package tooling is delegated.

## Users and purpose
Nanostack developers compose consistent application layouts from independently reusable, typed blocks. Initial consumers are Echopoint and Anchor. Product data, routing, authentication, and permissions remain application-owned.

## Capabilities and constraints
Public components support finite typed variations and never accept custom CSS. Consumer components cannot pass className, style, css, or arbitrary token values. Changes to the visual vocabulary belong in the library. The first Echopoint adoption is an authenticated beta home route.

## Brand commitments
The user accepted a refined, compact direction inspired by Linear, with Nanostack branding. Both themes are supported by the library; Anchor retains its light-only policy.

## Evidence
Existing product source and documented research are the evidence. Showcase records are labeled examples, never production measurements.
